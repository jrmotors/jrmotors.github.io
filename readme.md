## Стек

Чистые HTML, CSS и JavaScript без фреймворков и сборки. Сайт работает на любом статическом хостинге и открывается даже из файла (`file://`).

- Шрифты Google Fonts: **Unbounded** для заголовков и **Manrope** для текста. Оба поддерживают казахскую кириллицу.
- Два языка: русский и казахский. Выбор посетителя сохраняется в `localStorage`.
- Заявки приходят через WhatsApp (ссылка `wa.me` с готовым текстом) или звонком. Сервера нет.
- Карта: встроенная Google Maps и кнопка «Открыть в 2GIS».

## Структура

```
index.html            разметка; русский текст прописан прямо в HTML (для SEO и работы без JS)
assets/
  css/style.css       все стили; цвета и шрифты заданы переменными в :root
  js/config.js        контакты, часы работы, карта, ЦЕНЫ
  js/i18n.js          переводы RU/KZ всех текстов на странице
  js/main.js          меню, переключение языка, табы, анимации, ссылки WhatsApp
  img/                фото (WebP), логотип, монограмма, фавиконки
Logo.png              исходник логотипа (прозрачный фон)
brand.png             брендбук: как логотип выглядит на носителях
```

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте http://127.0.0.1:8080. Можно и просто открыть `index.html` в браузере.

## Как вносить правки

**Контакты, часы работы, цены** правятся только в [`assets/js/config.js`](assets/js/config.js). Скрипт сам подставит их во все ссылки и подписи на странице.

```js
phone: '+77763096199',            // для ссылок tel:
phoneDisplay: '8 776 309 61 99',  // как номер видят посетители
whatsapp: '77763096199',          // номер для wa.me, только цифры
hours: { ru: '...', kz: '...' },
PRICES: [
  { cat: 'light', ru: 'Компьютерная диагностика', kz: 'Компьютерлік диагностика', from: 5000 },
  // cat: 'light' — легковые, 'truck' — грузовые, 'mobile' — выезд
]
```

После изменения часов работы обновите и статическую копию в блоке JSON-LD в `index.html` (`openingHours`): её читают поисковики, которые не выполняют JavaScript.

**Тексты** хранятся в двух местах:
1. в `index.html` — русский вариант;
2. в [`assets/js/i18n.js`](assets/js/i18n.js) — словари `ru` и `kz`.

Меняя текст, правьте оба места. Ключ перевода стоит в атрибуте элемента: `data-i18n="..."`, `data-i18n-html="..."` или `data-i18n-attr="..."`.

**Фото** лежат в `assets/img/` в формате WebP. Чтобы заменить фото, положите новый файл под тем же именем. Если пропорции другие, обновите `width` и `height` у тега `<img>` в `index.html`.

## Фирменный стиль

- Цвета: чёрный `#0a0a0b`, графит `#121214` / `#1a1a1d`, текст `#ececee`. Фирменный красный `#d60404` снят пипеткой с логотипа.
- Заголовки: металлический градиент, заглавные буквы, шрифт Unbounded.
- Фирменный элемент — красный скошенный параллелограмм из буквы «R». Он повторяется в кнопках, маркерах, табах и таймлайне.

## Деплой

Сайт публикуется через **GitHub Pages** из ветки `main`, папка `/` (корень репозитория). Изменения появляются на сайте через 1–2 минуты после пуша.

```bash
git add -A
git commit -m "Описание изменений"
git push
```
